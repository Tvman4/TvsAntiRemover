# TV's Anti Remover

Simple Android utility that opens a local `data.unity3d` (or any) file and searches for a fixed list of anti-cheat related class name strings in UTF-8 and UTF-16LE encodings.

## Build

Open in Android Studio or run GitHub Actions workflow `.github/workflows/build.yml`.

Debug APK is produced at `app/build/outputs/apk/debug/`.
